# 📊 Instagram Social Media Analysis – SQL Project

## 📌 Project Overview

This project analyzes Instagram-style social media data using **SQL** to understand user behavior, engagement patterns, content performance, follower relationships, and opportunities for targeted marketing.

The analysis was designed from a **Data Analyst perspective**, with the goal of helping the marketing team improve:

- User acquisition
- User retention
- User engagement
- Content strategy
- Influencer marketing
- Personalized advertising

---

## 🎯 Business Problem

The marketing team wants to leverage Instagram user data to develop targeted strategies that can increase **user engagement, retention, and acquisition**.

The project answers business questions related to:

- User activity
- Engagement rates
- Influencer identification
- User segmentation
- Hashtag performance
- Content engagement
- Follower relationships
- Inactive-user re-engagement
- Marketing campaign opportunities
